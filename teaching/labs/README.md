# teaching/labs

Three kinds of page live here, all reached from the catalogue at
`/teaching/labs/`. No front matter on this file, so Jekyll copies it verbatim
rather than rendering it as a page.

| Kind | What it is | Where |
|---|---|---|
| Lab | Rebuild the algorithm from scrambled pseudocode, then the notebook opens. | `guided/lab<N>-<name>.html` |
| Applet | One page to play with. Nothing to hand in, nothing gated. | `applets/<course>/<name>.html` |
| Concept map | A chapter's theorems with the arrows blank. Match each to its statement. | `maps/<name>.html` |

A page file is front matter only, or front matter plus its own markup for an
applet. Everything else is either engine code or generated data.

The lab directory is `guided/` rather than `labs/`, which would read
`/teaching/labs/labs/lab1-runge/`. `LAB_DIR` in `index.html` is the one place
that knows the name; a lab card carries an id, not a filename.

## Layout

    index.html            the catalogue; one self-contained file, `cat-` prefix
    guided/               lab pages, one file per lab
    applets/<course>/     applet pages, one directory per course
    maps/                 concept map pages

    engine/
      shell.css           the standalone page shell all three kinds load first
      lab/                interp, verify, puzzle, feedback, lab.js, lab.css
      map/                map.js, map.css
      applet/             applet.js, applet.css

    data/                 generated by tools/; do not hand-edit
      specs/              one lab spec per lab, plus index.json
      maps/               one data file per concept map
      figures/<lab_id>/   setup figures captured from the notebook run

    notebooks/            the numerical analysis, DE and intro notebooks
    worksheets/           the printable concept map worksheets, generated
    vendor/               pinned third-party code; see vendor/README.md

`data/specs/` and `data/figures/` have to stay siblings: a spec names its
figures relative to `data/`, and `engine/lab/lab.js` resolves them by stripping
the spec's filename off its URL.

`notebooks/` is in `_config.yml`'s exclude list. Colab opens a notebook from its
GitHub blob URL, not from this site, and a lab is the way into its notebook.

## Building and checking

Everything that writes into `data/` or `worksheets/` lives in `tools/`, which is
also excluded from the site. See `HANDOFF.md` at the repo root for the pipeline,
the editorial rules and how to run the tests.
