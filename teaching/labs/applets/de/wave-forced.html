Forced wave equation

Here we push on a string that's pinned at both ends, with a force that varies along the string and not with time. Push on something once and you expect it to settle where you've pushed it, but there's no damping in this equation, so nothing ever decays. Instead the string oscillates forever about the shape the force would have held it in, and that's the dashed curve: \(v(x)\), the solution of \(c^2 v'' + \sin(2\pi k x) = 0\) with both ends pinned.

\[ u_{tt} = c^2 u_{xx} + \sin(2\pi k x), \qquad u(0,t) = u(1,t) = 0, \qquad u(x,0) = u_t(x,0) = 0 \]
