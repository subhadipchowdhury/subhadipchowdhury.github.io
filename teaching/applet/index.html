🐍 Running the activities

The Python activities run in JupyterLite, executing NumPy, Matplotlib, SymPy, and related libraries directly in the browser through Pyodide and WebAssembly. The first launch downloads the runtime (about 20 seconds); afterward it is cached and opens immediately. Nothing is installed, and no account is required.
