🐍 How the activities run

Each activity opens in JupyterLite, which runs Python (numpy, matplotlib, sympy, mpmath, ipywidgets) entirely in your browser via Pyodide/WebAssembly. The first launch downloads the runtime (~20 s); after that it's instant, and everything stays on your machine — no server, no login.
